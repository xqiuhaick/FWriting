# 截图说明

请将以下 PNG 文件放在本目录，供根目录 `README.md` 引用：

| 文件名 | 建议内容 |
|--------|----------|
| `editor.png` | 主编辑界面（含 Markdown 渲染） |
| `paragraph-focus.png` | 段落聚焦模式（当前段落高亮，其余淡化） |
| `export.png` | 导出面板或导出预览 |
| `ai-inline.png` | 选中文字后的 AI 药丸条（润色 / 翻译 / 续写 / 头脑风暴 / 快速创作） |
| `ai-summary.png` | 右侧检查器的智能章节摘要 |
| `project-encryption.png` | 项目加密与触控 ID / 密码解锁 |

建议宽度 1280px 左右，保持 macOS 窗口比例一致。
